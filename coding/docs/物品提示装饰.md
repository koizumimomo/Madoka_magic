# 物品提示装饰（衬底）

设计于 2026-11-16，2026-11-18 实装。契约、契约武器和悲叹之种的装饰共用 PixelFX 图集。

目标物品三类：魔法少女契约、三把契约武器、悲叹之种。

## 目标

给这三类物品的 tooltip 加一层「衬底」，让不读文字也能认出是哪一类。判据一句话：把文字全遮掉，三张框仍然能认出来。

- 契约是纸。
- 武器是兵。
- 悲叹之种是遗物。

## 不做

这些都是考虑过又砍掉的，别自己加回来：

- 不改排版，不加新文字行，不做 shift 展开的第二页。
- 不做名字逐字流光，不写自定义 `Font` 子类。
- 不反射往 `ChatFormatting` 里塞枚举值。
- 不做 tooltip 展开动画、剪刀揭幕、旋转星芒，不引入 shader。

现有 `client/ItemTooltipBorder.java` 已经给全部模组物品统一了羊皮纸框（`textures/gui/tooltip_borders.png`，64×32：四角 8×8 粉宝石角饰、上方蝴蝶金饰、下方黑宝石悬饰）。这次只在框里补衬底，不换框。

## 三层

1. **底板**：现有 `ItemTooltipBorder` 画。
2. **衬底**：本次新增，缎带 / 阵 / 粒子 / 右下角装饰。
3. **文字**：vanilla 原样。

## 绘制顺序

改 `ItemTooltipBorder.drawBorder` 里的序列，`EventPriority.LOWEST` 不动：

```
缎带 → renderTooltipBackground（底板）→ 阵 → 粒子 → 四角与上下饰件 → 右下装饰
```

三条注意：

- 缎带必须画在底板**之前**，露出的部分才在框外，画晚了会被底板压没。
- 阵和粒子画在底板**之后**、四角饰件之前，透明度压低，压在文字下面。
- 现有代码在 `renderTooltipBackground` 之后有一句 `graphics.flush()`，然后把 background / border 置 0。别把新绘制插到 flush 之后又依赖底色。

## 三类内容

| 物品 | 阵心 | 衬底 | 粒子 | 右下角 |
| --- | --- | --- | --- | --- |
| 契约（3 种性质） | 不画阵 | 两条 8px 缎带，斜穿，被底板压住中段 | 对应魔法少女的环绕粒子 | 羽毛笔，斜 45°，笔尖朝框内 |
| 契约武器（3 把） | 外环 + 内层符号 | 无 | 6–10 个光点，1.5–3 px/s 上漂 | 无 |
| 悲叹之种（各魔女变体） | 外环 + 来源魔女纹章 | 无 | 来源魔女的环绕粒子 | 无 |

## 参数

- **阵**。直径 `min(框宽, 框高) - 12`，20 秒转一圈，亮度低于文字。种子的阵心优先复用 `witch_rune/`，其次复用 `witch_kiss/` 源纹章，通用种子使用图集内符号。
- **武器微光**。8 个 2×2 px 光点，初相位按武器 ID 确定。寿命 4–8 秒，按 1.5–3 px/s 向上漂并在边缘淡出。
- **缎带**。两条 8px 宽的斜缎带，中心横向偏移 ±(框宽 × 0.18)，伸出上下边缘约 8px。两端保持原像素尺寸，中段随提示框高度拉伸。献身为金色，索取为蜜金色，赎罪为藏蓝色。
- **羽毛笔**。16×16，叠在右下角饰件旁。原版定位器会给契约的缎带与羽毛笔预留屏幕边距。
- 动画相位按 `Util.getMillis()` 计算。

## 代码入口

- `client/ItemTooltipBorder.java`：`drawBorder` 在角饰之前调用 `client/renderer/RitualItemParticles.java`，用现有角色贴图绘制粒子。
- `client/renderer/TooltipDecorations.java` 绘制衬底，读取 `ContractItem.getThemeId`、`ContractWeapon.of` 与 `GriefSeedItem.getOwner` 选择样式。资源重载时刷新可用纹章。
- `coding/tools/render-tooltip-decor.mjs` 生成图集。`coding/tools/render-spell-gui.mjs` 的 `--witch-only` 模式单独导出六张紫黑技能图标。

## 验收

1. 三类各截一张图，遮掉文字后仍能认出类别。
2. 依次悬停不同物品时没有残留：相位和粒子状态随 stack 重置，不跨物品复用。
3. 背包和快捷栏两个 tooltip 前后出现不串图。
4. 打开物品栏时帧数不掉；每帧新增 blit 数量控制在几十个以内。
5. 缎带伸出框外的部分不被裁剪，注意 scissor 状态。

## 手感备忘

- 透明度第一次做建议比直觉再低一档。压字是这类装饰最容易翻车的地方。
- 阵转一圈别快过 15 秒，快了像加载图标。
- 粒子总数上限 10 个，多了像下雪。
- 三类共用同一套绘制代码，差异只在参数和阵心贴图。别写成三份。
