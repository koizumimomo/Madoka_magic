# 物品文案与联动魔女粒子

2026-11-18。契约、悲叹之种和魔女之吻新增风味文本与用途说明，十二位联动魔女新增 PixelFX 专属环绕粒子。本轮只修改源码和资源，未打包 JAR。

## 文案

三种契约各有两行风味文本。三个旧版通用物品仍能按 NBT 性质读取，新旧物品和来源未明的物品都支持兜底描述。

| 契约 | 风味文本 |
| --- | --- |
| 献身 | 把最后一页留给你，把燃尽的自己留给初恋。 |
| 索取 | 让空缺的掌心盛满蜜糖，再借一颗心，填补下一次渴望。 |
| 赎罪 | 把说不出口的歉意，写成替你承受的愿望。 |

二十三种魔女的悲叹之种和魔女之吻各有独立的一句风味文本，并提供简体中文和英文。文字在语言文件的 `lore.madoka_magic.contract.*`、`lore.madoka_magic.grief_seed.*` 和 `lore.madoka_magic.witch_kiss.*` 下，游戏内用途说明在 `tooltip.madoka_magic.*` 下。

用途说明遵循当前玩法：

- 契约：右键阅读，确认后消耗契约；已有魔法少女身份时无法重复签约。
- 悲叹之种：显示当前每次净化的污染值和剩余净化次数；玩家魔女来源仍显示「来自【玩家名】」。净化量进入世界后读取服务端同步值，未进入世界时读取本地配置；配置为零时显示净化已禁用。
- 魔女之吻：说明每位玩家首次击败同种魔女时获得，属于没有使用效果的收藏纪念品。后续已补齐 23 种来源的独立纹章，并加入「展示环」。

文案只用于物品提示，不改变合成、掉落、伤害、污染或收藏记录。入口为 `item/ItemLore.java`，三类物品调用各自的 `appendHoverText`。服务端净化量通过已有的 NBT 状态包同步，`RitualTooltipValues` 不参与净化结算。

## 粒子

每位联动魔女有两种原创图案，每种 32×32 像素、四帧循环；总共 24 种图案、96 帧。绘制工具使用工作区的 PixelFX，脚本在 `tools/render-external-witch-particles.mjs`。图集在 `textures/particle/external_witch_orbits.png`，256×384 像素，8 列、12 行，保留透明背景与硬像素边缘。

| 魔女 | 图集行 | 图案 |
| --- | --- | --- |
| 蛮勇 | 0 | 熔牙、火山碎屑 |
| 悔恨 | 1 | 裂心、泪痕碎片 |
| 甘美 | 2 | 奶油蛋糕、糖纸 |
| 锻造 | 3 | 铁砧、熔铆钉 |
| 燃烧 | 4 | 火舌、卷曲余烬 |
| 守护 | 5 | 封印石门、锁链 |
| 预兆 | 6 | 日蚀、断裂星轨 |
| 深渊 | 7 | 紫黑漩涡、深渊触腕 |
| 紫晶 | 8 | 晶簇、裂开的晶洞 |
| 遗迹 | 9 | 断柱、沙漏 |
| 咒罚 | 10 | 黑羽、天秤 |
| 海妖 | 11 | 螺壳、潮纹 |

四芒星头环沿用原有配色与样式。新的全彩粒子按首领宽高向外展开，保留原有抛散、收束、束缚、倒行、波动和游行运动。半透明粒子使用深度测试和全亮材质；当前最多按配置绘制，默认每只首领八枚，不额外生成服务器粒子实体。

数据在 `visuals/witch_styles.json` 的各主题 `orbit` 对象内，支持资源重载：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `row` | 每个主题独立 | 图集所在行 |
| `count` | 8 | 同时显示的粒子数，允许 1–24 |
| `size` | 0.19 | 单枚粒子的基础半尺寸，按首领体型缩放 |
| `radius` | 0.8 | 首领碰撞箱外的基础环绕距离 |
| `speed` | 0.019 | 每游戏刻的环绕角速度 |
| `height_spread` | 0.55 | 相对首领身高的上下分布范围 |
| `frame_ticks` | 5 | 单帧持续的游戏刻数 |

`ExternalWitchParticles` 负责图集取帧和轨迹，`ExternalWitchVisuals` 接入实际首领渲染。`RitualItemParticles` 复用同一图集，悲叹之种和魔女之吻的物品提示同步显示来源魔女的图案。原有魔女与三系变身粒子继续使用各自原图。

## 验证与记录

PixelFX 图集导出时检查透明边界、非空图案、帧变化和循环周期，并检查最终图集的透明背景。隔离客户端记录在工作区 `.tmp/item-lore-orbits-qa`，包括三类物品文案、旧 NBT 与来源信息、服务端净化量、全部十二种图集行，以及实际 AC 2.0.2 的甘草女巫、遗弃者和暝煌龙的渲染。灾变本体的完整战斗和多人表现仍按原待办继续验收。

实际暝煌龙测试发现结界保护把 `EntityMobGriefingEvent` 当作可取消事件，会触发 Forge 异常并崩溃。已在 `BarrierGuardEvents` 改为 `setResult(Event.Result.DENY)`，通过 Forge 的结果接口维持禁止破坏地形的规则，回归中显式检查该查询返回禁止。
