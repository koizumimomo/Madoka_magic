# 咒具设计表

2026-11-20。每个魔女对应一件咒具，装备在 Curios 咒具栏。获取方式是祭坛消耗一颗满耐久的悲叹之种（加紫水晶触媒），用同主题的满耐久种子升级。

## 通用规则

- 每件只给一项主属性：攻击、魔法强度、护甲，避免全能件。
- 被动从 L1 起步，最高 L3，每级大约 1.3 倍。
- 玩家性质和咒具主题一致时，被动数值 +20%。
- 所有效果挂现有事件（伤害、击杀、受击、施法、位移），不引入新战斗框架。
- 数值全部待实测调整。
