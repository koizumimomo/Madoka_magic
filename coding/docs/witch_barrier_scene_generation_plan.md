# 魔女结界场景生成设计方案

> 目标版本：Minecraft Forge 1.20.1  
> 方案状态：设计提案，尚未进入代码实现  
> 核心选择：混合型地形、半随机布局、固定 Boss 竞技场

## 1. 设计目标

魔女结界首先是 Boss 战斗的舞台，其次才是可探索空间。玩家进入结界的主要目的通常是找到并击败魔女，因此场景应优先做到：

- 进入后迅速建立鲜明的主题印象。
- 让入口、通往 Boss 的路线和竞技场清晰可靠。
- 通过地形轮廓、近景装饰、远景巨构和环境效果营造异质感，而不是堆叠必须探索的内容。
- 使用可复用的生成模块，避免每个魔女都需要一套独立生成系统。
- 同一世界中的同一结界布局稳定可复现。

总体结构：**固定战斗核心 + 半随机外围场景 + 远景视觉巨构**。

## 2. 场景分层

每个结界由若干可组合层构成：

1. **基础地形**：玩家实际行走的地表。
2. **次级地形**：柱状平台、浮岛、断裂地块、阶梯、盆地等。
3. **近景装饰**：遗迹、植物、机械、雕像和主题物件。
4. **远景巨构**：远处的巨型建筑、树木、钟楼、拱门、阶梯等，优先考虑贴图渲染。
5. **环境表现**：天空、雾、色调、粒子和环境音效。
6. **固定战斗区域**：出生点、Boss 竞技场、必要通路和出口。

地形类型与装饰类型应解耦。同一基础地形可以搭配不同装饰，同一种装饰也可以出现在不同地形中。

## 3. 基础地形类型库

### 3.1 无限起伏平原（优先实现）

大范围连续地表，只有缓慢起伏、浅坑和小丘；远处由雾气或天空边界遮挡，营造无尽感。

- 使用低频噪声决定大尺度地势。
- 叠加较弱的中频噪声，形成小丘和浅坑。
- 可选叠加极弱的高频变化，避免地表过于机械。
- 初版可测试基础高度上下约 4–8 格，再按移动体验调整。
- Boss 战斗核心区域不应产生明显坡度。

适合空旷、孤独、压抑或梦境感较强的结界。

### 3.2 独立柱状平台

由大量互不连接或少量连接的柱体构成，高度、宽度和间距错落。

- 使用网格抖动或泊松采样选择平台中心，避免棋盘式排列。
- 随机决定平台半径、轮廓、高度和顶部材质。
- 控制最小间距，避免平台互相吞并。
- 为玩家保留可通行路线；危险落差应有明确视觉提示。
- 避开出生点、Boss 竞技场和关键通道。

### 3.3 浮岛与悬浮平台

少量地块悬浮在空中，可带下垂岩柱、碎片或主题装饰。控制数量和高度范围，作为空间变化而非让整个世界都变成浮岛。不可到达的浮岛应明确作为背景景物；可到达的浮岛则要考虑安全落点和返回路径。

### 3.4 阶梯状地形

地表分成若干高度层，形成平台、断崖和宽阔台阶。先生成大区块高度层，再对边缘做少量随机化。台阶宽度应足以通行，避免频繁跳跃成为强制操作。

### 3.5 巨型凹陷盆地

外围较高，地形向中心缓慢下降，中心可设置视觉焦点或战斗场地。轮廓可采用不规则椭圆并用低频噪声扰动。若中心是 Boss 竞技场，竞技场仍使用固定模板，不由噪声决定。

### 3.6 断裂地表

地面被裂缝分割成大块地台，局部高低错落，少量碎片悬浮。先确定大块地表轮廓，再生成裂缝，避免区块独立切割造成接缝。裂缝可分为纯装饰和真实危险区域。

### 3.7 放射状与环形地形

以中心点向外形成同心环、放射状平台或分层圆环。适合用于固定竞技场外围，但不建议所有魔女都采用强中心对称布局。

### 3.8 迷宫与墙体地形

由墙壁、走廊、房间和断裂通道组成。以视觉迷宫为主，不必制作复杂寻路谜题；保留清晰主通路，避免玩家为了找到 Boss 而长时间绕路。

## 4. 近景装饰与空间异常物

近景结构应少量、主题明确，并避免遮挡玩家视线或 Boss 战斗。可复用的装饰类别：

- 枯木、巨型花朵、蘑菇、藤蔓和荆棘。
- 断柱、拱门、残墙、雕像和建筑残骸。
- 齿轮、钟表、玩具、木偶和舞台道具。
- 蜂巢、蜜池、漂浮容器、餐桌等主题物件。
- 沉船、乐谱、气泡、海草等水域意象。
- 悬浮楼梯、重复拱门、没有内部的建筑、倒置结构等异常物。

这些结构主要用于建立视觉主题，不要求每个物件都可交互。

## 5. 远景巨构：优先使用贴图渲染

考虑到玩家通常只是进入结界击败 Boss，远处的巨型建筑和异常结构不必全部用真实方块搭建。**推荐将远景巨构制作成透明 PNG，在远处以面片（billboard）或定向平面渲染。**

适合贴图化的对象：
- 远方巨型钟楼、城堡、塔楼和拱门。
- 超大枯树、花朵、蘑菇或雕像。
- 悬浮楼梯、环形结构和断裂建筑。
- 远处重复排列的柱群或城市轮廓。

### 渲染建议

- 使用透明 PNG，保留轮廓和必要的半透明细节。
- 将远景分为远、中、近几层，利用不同距离和少量视差增加空间感。
- 远景面片可朝向摄像机，也可固定朝向；有明确正面的钟楼、城堡等优先使用固定朝向或交叉面片，避免转动感。
- 结合雾色、天空色和距离淡出，让贴图融入环境。
- 通过高度、尺度和距离变化避免所有物体像贴在天空上的广告牌。
- 可用少量低多边形模型补充轮廓厚度，不建议所有远景都做成实体方块结构。

### 注意事项

- 远景贴图只负责视觉，不应被误认为可到达的平台或建筑入口。
- 不要遮挡 Boss、使魔或战斗提示。
- 注意透明排序、深度测试、雾效兼容和视角边缘露馅问题。
- Billboard 巨构可能随视角旋转；大型建筑优先考虑固定朝向。
- 远景资源按魔女主题配置，不必每个结界都堆满巨构。

## 6. 固定 Boss 竞技场与战斗动线

Boss 竞技场采用固定布局，外围地形采用半随机布局。每个结界至少定义：

- 玩家进入后的出生点。
- 通往 Boss 区域的主路线。
- Boss 出生点或竞技场中心。
- 传送出口或离开位置。
- 必要时设置使魔活动区域。

竞技场可采用独立结构模板或固定坐标区域。随机地形生成时必须避开这些区域，并为主路线保留足够宽度和安全高度。

建议将场景分为入口缓冲区、过渡区域、Boss 竞技场和出口区域。玩家不应被迫长时间寻找 Boss；场景的主要价值是营造氛围和衬托战斗，而不是增加无必要的跑图时间。

## 7. 半随机生成策略

采用“固定骨架 + 稳定随机细节”：

- **固定**：入口、Boss 竞技场、主路线、出口和关键地标。
- **半随机**：外围平台位置、局部高度、装饰物数量、朝向和少量结构组合。
- **可选随机**：环境粒子、装饰动画或远景组合。

### 随机种子与区块边界

建议使用世界 Seed、结界维度标识和生成模块标识共同派生随机种子。随机结果应由全局坐标决定，不能简单地让每个区块独立掷骰子。

生成某区块时，应同时检查可能影响该区块的邻近采样区域；跨区块结构使用统一坐标和随机结果，避免平台断裂、重复或接缝。

## 8. 通用模块划分建议

以下为逻辑职责，不要求必须一一对应 Java 类；应先检查项目现有架构再确定实现：

| 模块 | 职责 |
|---|---|
| BarrierTerrainGenerator | 基础地形，如起伏平原、盆地、阶梯 |
| BarrierPlatformGenerator | 柱状平台、浮岛、断裂地块 |
| BarrierStructureGenerator | 建筑、迷宫、遗迹和大型近景结构 |
| BarrierDecorationGenerator | 植物、杂物、主题装饰 |
| BarrierArenaPlacer | 固定竞技场、出生点、主路线和出口 |
| BarrierFarSceneryRenderer | 远景贴图、面片和距离淡出 |
| BarrierEnvironmentController | 天空、雾、粒子和环境音效配置 |
| BarrierGenerationConfig | 每个魔女的生成参数组合 |

## 9. 魔女主题组合示例

以下是概念组合，可按最终角色设定调整：

| 结界主题 | 基础地形 | 次级地形 | 近景装饰 | 远景巨构 |
|---|---|---|---|---|
| 蝴蝶 | 无限起伏平原 | 少量断裂平台 | 枯萎花园、花茎、蝴蝶标本 | 巨型枯树、远方拱门 |
| 索取 | 巨型凹陷盆地 | 零散柱状平台 | 蜂巢、蜜池、餐桌意象 | 巨型蜂巢轮廓、倾斜塔楼 |
| 赎罪 | 阶梯状地形 | 孤立高台、少量浮岛 | 冰晶、荆棘、审判意象 | 巨型尖塔、远方冰封建筑 |
| 悲伤 | 平缓地形或失重水域意象 | 悬浮平台 | 沉船、乐谱、海草 | 水下建筑轮廓、远方穹顶 |
| 凋零 | 断裂地表或起伏平原 | 黑色石柱 | 枯木、灰烬、残骸 | 巨型枯树、远方废墟 |
| 胡桃夹子 | 迷宫式或阶梯地形 | 环形平台 | 玩具、齿轮、木偶舞台 | 玩具城堡、巨大钟表 |

不应强制每个结界使用完全不同的地形算法。通过“相同地形模块 + 不同参数 + 不同装饰与远景”即可形成差异。

## 10. Forge 1.20.1 实现路线

### 阶段一：基础地形原型
- 保留现有维度和基础生成方式。
- 实现无限起伏平原。
- 实现柱状平台和少量浮岛。
- 验证区块边界连续性、性能和玩家通行体验。

### 阶段二：固定战斗核心
- 为每个结界确定入口、Boss 竞技场、出口和主路线。
- 随机生成必须避开固定区域。
- 验证不同种子下战斗场地始终可用。

### 阶段三：近景结构和装饰
- 增加断裂地表、阶梯、盆地等模块。
- 接入结构模板或项目已有的结构放置机制。
- 为各魔女配置不同装饰组合。

### 阶段四：远景贴图渲染
- 制定远景巨构 PNG 资源规范。
- 实现固定朝向面片或 billboard 渲染。
- 加入雾效融合、距离淡出和分层视差。
- 测试透明排序、视角边缘和不同显卡环境。

### 阶段五：环境表现
- 配置天空、雾色、粒子和环境音效。
- 适量加入场景动态，不影响 Boss 战斗辨识度。

## 11. 性能与体验约束

- 避免每个区块生成大量独立方块结构。
- 远景巨构优先使用少量渲染面片，而不是大量实体或方块。
- 装饰数量应有上限，并可按距离或区块卸载。
- 随机地形不得影响 Boss 战斗的碰撞、寻路和技能判定。
- 玩家出生点附近不得生成高落差、封路或遮挡视线的结构。
- 远景装饰不应被误认为可探索目标。
- 调试时保留固定 Seed 和生成参数记录。

## 12. 首个可交付原型建议

先只制作一个测试结界：

- 基础地形：轻微起伏的无限平原。
- 次级地形：少量柱状平台、少量浮岛和局部断裂地块。
- 近景装饰：少量主题遗迹或植物。
- 远景：2–4 组不同距离和高度的巨构贴图面片。
- 战斗区域：固定竞技场，外围生成逻辑主动避让。
- 随机策略：同一世界 Seed 下稳定，外围细节半随机。

先验证这套组合是否能显著改善“超平坦 + 方块平铺”的观感，再逐步扩展到其他魔女。

---

**最终原则：结界首先是 Boss 战斗的舞台，其次才是可探索空间。** 用有辨识度的地形轮廓、少量近景结构、远景贴图巨构和环境氛围，创造强烈的魔女异界感，而不必把每个结界都做成庞大复杂的开放地图。
