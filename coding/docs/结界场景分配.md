# 结界场景分配

2026-11-22。每个魔女结界的场景构成：固定骨架（出生平台 → 主路线 → 竞技场）加半随机外围地形和远景巨构。按魔女的性质决定地形模块、装饰和氛围。

配套阅读：[witch_barrier_scene_generation_plan.md](witch_barrier_scene_generation_plan.md)（生成方案总纲）。

## 1. 固定骨架

进入结界后的动线固定，不参与随机：

| 部件 | 规格 | 说明 |
|---|---|---|
| 出生平台 | 13×13，高出外围地形 1–2 格 | 传送门出口，四周有方向指示物 |
| 竞技场 | 半径 20 的方形或圆形平地，围墙高 3–5 | 只有魔女本体在这里生成，地形生成必须避让 |
| 缓冲带 | 竞技场外 10 格 | 不做起伏和装饰，防止地形插进战斗区 |
| 主路线 | 宽 5–7，长 96 格（约 6 区块） | 连接出生平台与竞技场，按主题换皮肤（桥、柱链、台阶、浮岛跳跃） |
| 底部 | 不铺基岩层 | 玩家掉出地形按「仁慈的虚空」处理，传送回附近平台上方（参考 forgivingvoid 1.20.1-10.0.3） |
| 穹顶 | 仅会跳/飞的魔女启用 | 高 25–30，其余用矮墙加隐形边界 |

所有使魔都生成在竞技场外（半径 20 格以外），竞技场内只有魔女本体。结界内的方块不可破坏。

竞技场方向固定：出生平台正前方 96 格。配合现有的魔女方向指示，玩家不会迷路。竞技场一次放置，不随区块重复生成；外围地形按世界 seed + 维度 key + 模块 id 派生，同一结界每次一致。

## 2. 地形模块库

| 编号 | 模块 | 参数 |
|---|---|---|
| PLAIN | 无限起伏平原 | 低频大起伏 ±6，中频浅坑 ±2，竞技场与主路线周围压平 |
| PILLARS | 柱状平台 | 平台半径 3–7，高度差 4–14，最小间距 6，少量连接桥 |
| ISLES | 浮岛 | 每 2–3 区块 1–3 座，高度 8–30，带下垂岩柱 |
| TERRACE | 阶梯地形 | 大块高度层差 6–10，台阶宽 4–6 |
| BASIN | 巨型凹陷盆地 | 外围高、中心低，坡度缓，中心可放竞技场 |
| FRACTURE | 断裂地表 | 地台被裂缝分割，落差 3–8，少量悬浮碎块 |
| RING | 环形地形 | 同心环或放射平台，只用于竞技场外围，不超过 2 层 |
| MAZE | 迷宫墙体 | 主通路保留，墙体高 3–6，只做视觉迷宫 |

近景装饰按主题从候选项里挑 3–5 类，单块区域数量设上限，不遮挡视线。远景巨构走透明 PNG 面片，每个结界 2–4 组。

模块与竞技场的放置逻辑参考既有生成方案 §8 的职责划分。竞技场和出生平台用固定结构模板，外围地形按 seed 派生。

## 8. 优先级

1. 先做固定的三件：出生平台、主路线、竞技场（圆形和方形各一套模板）。
2. 再做外围地形模块：PLAIN、PILLARS、ISLES 三个最有辨识度，先覆盖大部分结界。
3. 然后是近景装饰和远景巨构，按主题一批批加。
4. 最后补 TERRACE、BASIN、FRACTURE、RING、MAZE 和特殊竞技场（半水、穹顶、舞台）。

首个可交付样张建议做 sacrifice：PLAIN + 局部断裂、断桥柱链、枯树与断拱巨构，验证整套流程。
