## 零、什么叫"可玩"（验收定义）

一句话：从空手进世界，到完成一次
**拿祭坛 → 拿材料 → 契约 → 打怪 → 污秽满 → 魔女化 → 找到并击败自己的魔女 → 悲叹之种 → 净化 → 继续**

验收清单（每条都要能实测）：

| # | 验收项 |
|---|---|
| 1 | 生存模式能获得祭坛与黑色郁金香（不靠创造） |
| 2 | 契约后 HUD 能看到**魔力**与**污秽**，数值变化实时 |
| 3 | 5 个主动技能全部可用；冷却中 / 魔力不足 / 没有目标都有明确反馈 |
| 4 | 污秽到 60 / 80 / 100 有提示，玩家能预判魔女化 |
| 5 | 污秽满 100 → 死亡 → 原地生成魔女，魔女**可见**、有名牌、有血量 |
| 6 | 重生后玩家能再找到这只魔女并击败它（不卡在隐形/无敌） |
| 7 | 悲叹之种能把污秽压回去，净化数值符合设计（当前 ×50% + 15） |
| 8 | 死亡、重生、退出重进存档都不丢状态（宝石/污秽/技能/魔女） |

### 🟡 半成品（有壳，但玩起来会露馅）

| 模块 | 缺什么 |
|---|---|
| 魔女实体 | **没有客户端渲染器 → 实体完全隐形**；只有近战 AI，没有 A 主题行为；无血量显示 |
