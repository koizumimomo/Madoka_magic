# 献身系 · 魔法少女技能设计（A · 蝴蝶系）

> 状态：**已实现**（2026-11-08 落地，代码可运行）
> 上游文档：`魔法少女技能设计.md` §一（原型 A）· `魔法少女小圆主题模组-设计提案.md` §16
> 本文件是献身系的**实现级说明**：数值、状态机、代码位置、已知偏差。

---

## 零、定位

| 项 | 内容 |
|---|---|
| 名称 | 献身 |
| 分类 / 定位 | 献身型 · 持续输出型 |
| 主元素 | 蝴蝶 / 黑色郁金香 |
| 配色 | 黑 + 黄（`#F2C14E` / `#111014`） |
| 契约材料 | 黑色郁金香 `madoka_magic:black_tulip` |
| 魔力总量 | 140 |
| 伤害 / 受伤 / 污染 / 魔力获取 | +10% / +10% / +20% / +5% |
| 核心资源 | 魔力（烧）→ 污染 |
| 情绪曲线 | 燃烧 |

**一句话**：她越想赢，就得越久地待在战斗里；待得越久，最后那一下"花落"的代价就越重。

**完整循环**

```
普攻/技能挂蝴蝶标记 → 放花粉收割标记 → 开花期输出（魔力在烧）
  ├─ 打得顺：加成随战斗时长一路涨，直到魔力烧完
  ├─ 魔力烧完 → 立刻花落：加成清零、属性下降、污染上涨
  └─ 5 秒脱战：没花落就安全退出；已花落则 +15 污染，属性下降保留到睡醒
危急时凋零：拿命或拿污染换爆发
```

## 一、主动技能（5 个）

轮盘（R 键）里的顺序按解锁等级排。数字键可直选，**Shift + 施放**触发凋零的污染代价。

### 蝶翼斩 · `butterfly_slash`

| 项 | 值 |
|---|---|
| 解锁 | Lv1 |
| 冷却 / 魔力 | 4 秒 / 6 |
| 基础伤害 | 6.0（走统一伤害公式） |
| 附带 | 回复 1 点生命 |

命中后由**献身之翼**被动挂上蝴蝶标记。

### 郁金香爆 · `tulip_burst`

| 项 | 值 |
|---|---|
| 解锁 | Lv3 |
| 冷却 / 魔力 | 10 秒 / 20 |
| 基础伤害 | 5.0（走统一伤害公式） |
| 范围 | 半径 4 格 |
| 附带 | 范围内每个敌人挂 1 层蝴蝶标记 |

### 花粉 · `pollen`

| 项 | 值 |
|---|---|
| 解锁 | Lv5 |
| 冷却 / 魔力 | 8 秒 / 12 |
| 范围 | 半径 6 格 |
| 每层标记加成 | +12% 伤害 |
| 持续 | 立即一跳 + 之后每 0.5 秒一跳，共 8 秒 |

**关键设计**：只对**带蝴蝶标记**的敌人生效，无标记的敌人完全免疫。
这让「先挂标记再收割」成为必须，而不是可有可无。

每跳的伤害在施放时按当时的标记层数算好并锁定，
所以即使标记中途过期，剩余的跳伤害也不会突然变弱。

> 实现：`spell/PollenTracker.java`（静态列表 + 每 tick 结算）

### 花期 · `blossom`

| 项 | 值 |
|---|---|
| 解锁 | Lv7 |
| 冷却 / 魔力 | 20 秒 / 10 |
| 绽放每秒耗蓝 | 6 |
| 加成增长 | 每战斗秒 +3%，上限 +60% |
| 花落脱战额外污染 | +15 |
| 花落属性下降 | 攻击 −15%、移速 −10%、魔力上限 −20% |

**核心机制**，状态机：

```
[休眠] ──施放──> [绽放] ──魔力耗尽──> [花落] ──脱战──> [休眠]
                    │                     │
                    │ 脱战                │ 属性下降 + 污染上涨
                    ↓                     ↓
              加成直接消失（无惩罚）    +15 污染，属性下降保留到睡醒
```

| 阶段 | 效果 |
|---|---|
| **绽放** | 每秒消耗 6 点魔力；造成的伤害随**战斗持续时间**线性增长（每秒 +3%，封顶 +60%） |
| **花落** | 加成立即清零；攻击 −15%、移速 −10%、魔力上限 −20%；污染每秒 +1.2（×宝石污染速率）；持续到脱战 |

**战斗判定**（已确认规则）：

- 花期**持续到战斗结束为止**，没有固定时长上限。
- 战斗结束 = **5 秒内没受到来自生物的伤害**。
  **只看挨打，不看输出**——你打别人不延长战斗。
- 脱战时若**尚未花落** → 加成直接消失，不产生惩罚。
- 脱战时若**已经花落** → 额外 **+15 污染**，属性下降**保留到睡一觉起床**（可恢复，非永久）。

> 实现：`spell/BlossomState.java`
> 属性下降用 `AttributeInstance.addTransientModifier`（1.20.1 没有公开的 `addModifier`），
> 起床恢复挂在 `PlayerWakeUpEvent`。

### 凋零 · `wither`

| 项 | 值 |
|---|---|
| 解锁 | Lv9 |
| 冷却 / 魔力 | 30 秒 / 15 |
| 基础伤害 | 10.0 × 范围倍率 |
| 范围 | 半径 4 格 |
| 生命代价 | 当前生命的 15% |
| 污染代价 | +10 污染 |
| 花落期间 | 伤害 ×1.5 |

**代价二选一**：

- 默认消耗**生命**（当前生命的 15%）；
- **按住 Shift 施放**改为消耗**污染**（+10 点）；
- 生命不足以支付时自动改为支付污染。

**设计意图**：A 的"最后一搏"。它把"付出代价"做成**主动选择**——
和花期那种"被动滑向代价"形成对照：玩家可以主动选用命换还是用污染换。

> 实现：网络包 `CastSpell` 带一个 `shiftHeld` 标志，轮盘点击时读 `hasShiftDown()`。

## 二、被动技能（3 个）

### 献身之翼 · `devotion_wing`（事件型）

你的**普攻与主动技能**命中敌人时，为其挂上**蝴蝶标记**。

| 项 | 值 |
|---|---|
| 层数上限 | 5 |
| 每层持续 | 12 秒（全部层数一起衰减，最后命中的那层决定总时长） |
| 存储 | 敌人实体的 persistent data（NBT） |

标记是 A 的"燃料"：花粉与花期都要吃它。
所以它**不是**独立技能，而是被动——不占用主动位。

> 实现：`spell/ButterflyMark.java`；过期判定放在读取时做，不需要心跳清理。

### 执念 · `obsession`（事件型）

每击杀一个敌人叠一层，每层提升 **8%** 伤害。

| 项 | 值 |
|---|---|
| 层数上限 | 5 |
| 持续 | 20 秒不吃击杀则全部清空 |

> 实现：`spell/MadokaPassives.java`

### 余晖 · `ember`（查询型）

污染值每 10 点提升 **2%** 伤害（污染 100 时 +20%）。

**设计意图**：献身系的污染速度是 +20%，配合这个被动形成"越危险越强"的循环。
这是一个**故意让污染变得有吸引力**的设计——它把污染从单纯的惩罚变成资源，
和"献身"的自我毁灭主题一致。

> 实现：`spell/MadokaPassives.java`

## 三、代码结构

| 文件 | 职责 |
|---|---|
| `spell/ButterflyMark.java` | 敌人身上的标记：叠层、读取层数、伤害倍率、过期 |
| `spell/BlossomState.java` | 花期状态机：绽放/花落、每秒耗蓝、属性下降修饰器、起床恢复 |
| `spell/MadokaPassives.java` | 献身之翼 / 执念 / 余晖的实现与倍率查询 |
| `spell/PollenTracker.java` | 花粉的持续跳伤害（静态列表 + 每 tick 结算） |
| `spell/MadokaSpellEffects.java` | 全部主动技能的行为实现 |
| `spell/SpellEffects.java` | 效果注册表；`PassiveEffect` 扩展了 `onDealDamage` / `onKill` 钩子 |
| `event/TaintEvents.java` | 伤害统一乘区、战斗时间记录、被动回调、魔女化 |
| `event/PlayerEvents.java` | 每秒结算花期与执念、起床恢复 |
| `data/PlayerMadokaData.java` | 战斗状态（`lastCombatTick`/`combatStartTick`）、花期阶段、执念层数 |

**数据驱动**：5 个主动 + 3 个被动的元数据（冷却 / 魔力 / 污染 / 解锁等级 / 图标）
全部在 `data/madoka_magic/spells/*.json`；换数值不用编译。

## 四、连带改动（实现过程中发现并修正的）

### 1. 污染值改成小数存储

设计里「施法 +0.3」「普攻 +0.2」是小于 1 的增量，而 `PlayerMadokaData.taint`
原本是 `int`，`Math.round(0.3)` 会变成 **0**——这两条规则此前**根本没生效**。

现改为 `float` 存储，`addTaint(float)` / `removeTaint(float)`，
网络同步也从 `writeVarInt` 改为 `writeFloat`。

### 2. 绒毛散归位到索取系

`dandelion_drift`（绒毛散）原本挂在献身系，但它在设计文档里属于
**蜂后系（索取）**的 B-4「蒲公英」。已移到 `take.json`。

### 3. 被动系统从空转变成事件驱动

原来的 `PassiveEffect` 只有 `apply` / `remove` 两个钩子，
而**没有任何地方调用它们**（`applyPassive` 全工程零引用），
所以 4 个被动此前都是纯装饰。

现在扩展了 `onDealDamage` / `onKill` 两个事件钩子，
并在 `TaintEvents` 的 `LivingDamageEvent` / `LivingDeathEvent` 里统一回调。

### 4. 被动与解锁改为按角色过滤

原来 `SpellRegistry.defaultUnlocked()` 按**全局** `unlock_level` 解锁，
`applyPassive` 也全工程零引用，导致：

- 索取系玩家在 Lv9 会解锁献身系的「凋零」；
- 献身系的专属被动「献身之翼」会让索取系玩家也挂蝴蝶标记；
- 换契约后旧的技能记录仍留在已解锁列表里。

现已改为：

| 位置 | 改动 |
|---|---|
| `SpellRegistry.defaultUnlocked(level, theme)` | 新增按角色技能表过滤的重载 |
| `SpellRegistry.passivesOf(theme)` | 按角色被动表取被动定义 |
| `PlayerEvents.refreshUnlocks` | 改用角色过滤版 |
| `ContractItem.confirmContract` | 换契约时清空旧技能，按新角色解锁 |
| `SpellCasting.castFromClient` | 校验技能属于当前角色 |
| `SpellWheelScreen` | 只显示当前角色的技能 |
| `TaintEvents` 被动回调 | 只遍历当前角色的被动 |

## 五、数值总表（速查）

```
伤害公式：最终 = (基础 × 纯度增幅 × 因果增幅) × (1 + 魔法强度) × 宝石倍率
       × 花期加成 × 执念加成 × 余晖加成

蝶翼斩   Lv1  CD 4s   魔力  6   伤害 6.0   单体
郁金香爆 Lv3  CD 10s  魔力 20   伤害 5.0   半径 4   挂标记
花粉     Lv5  CD 8s   魔力 12   伤害 2.0   半径 6   仅对带标记者
花期     Lv7  CD 20s  魔力 10   每秒耗蓝 6   加成 +3%/战斗秒（封顶 +60%）
凋零     Lv9  CD 30s  魔力 15   伤害 10.0  半径 4   生命/污染代价

标记：上限 5 层，每层 12 秒，每层 +12% 花粉伤害
执念：每层 +8%，上限 5 层，20 秒不吃击杀清空
余晖：每 10 点污染 +2%
花落：攻击 −15%、移速 −10%、魔力上限 −20%，睡醒恢复
```

## 六、已知偏差与待办

| # | 事项 | 说明 |
|---|---|---|
| 1 | **赎罪系已补齐**（2026-11-08） | 赎罪系 3 主动 + 3 被动已实现，见 `docs/赎罪系技能设计.md`。三个原型里只剩**索取系**没对齐设计。 |
| 2 | **花期加成不区分伤害来源** | 加成走 `LivingHurtEvent`，所以普攻与技能都吃——这符合设计（"走统一伤害公式"），但也意味着**非伤害来源**（如某些道具）也会吃到。 |
| 3 | **献身系只有 3 个被动** | 已确认规则是"至少 2 主动 + 3 被动"，献身系满足（5 主动 + 3 被动）。索取系 4 主动 + 3 被动满足；赎罪系 0 主动 + 2 被动**不满足**。 |
| 4 | **花粉无命中反馈** | 施放时若范围内没有带标记的敌人，静默无效果。玩家可能不知道为何没打中。 |
| 5 | **三个新图标是占位图** | `pollen.png` / `blossom.png` / `wither.png` 是按现有占位图风格生成的首字母图，等你替换。 |
| 6 | **花期没有主动取消** | 只能等魔力耗尽或脱战，玩家不能主动提前结束花期。 |
| 7 | **魔法少女打原版怪是满伤** | 按阵营划分，原版怪=魔女眷属=魔女侧，魔法少女打它们属于**跨阵营**，不吃 50% 减免（设计 §5.3 的原意）。若觉得手感偏弱，调 `faction.same_faction_damage_multiplier` 只影响真正同阵营的情况（打自家召唤物、打魔女）。 |
