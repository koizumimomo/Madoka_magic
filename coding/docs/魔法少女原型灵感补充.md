## 一、结论先说

1. **两条原型成立，而且比"再做一个愿望模板"更有价值。**
   它们填的是 v2.0 一直没填的那一层：主题、配色、叙事口吻。
   机制不动，变的只是"这套力量长什么样、为什么变这样"。

2. **原型 A/B 建议作为"动机维度"，与"学派维度"正交。**
   学派（9 选 1）决定**力量来源**，原型（2 选 1）决定**动机与代价形态**。
   9 × 2 = 18 种组合，而不是维护两套并行系统。
   这条建议也顺带回答了"如何成为魔法少女"——见第五节。

3. **蜂后与工蜂的生物学差异，几乎是两条原型的现成机制原型。**
   见第三节，这部分是本次检索最意外的收获。

4. **有一条原型元素（黄色郁金香）存在来源分歧**，见第二节。

### 2.1 黄色郁金香 —— 「无望的恋爱」（日语花语已确认）

**日语花语（母语语境，最权威）**：

| 来源 | 黄（黄色）チューリップ |
|---|---|
| hanakotoba.net（日本の花言葉サイト） | 日本：**望みのない恋／名声**；海外：望みのない恋、**報われぬ恋**、明るさ、日光 |
| b-post（チューリップの花言葉） | 黄色いチューリップ：望みのない恋、報われぬ恋、明るさ、日光 |
| hana-kotoba.site（英語版花言葉） | Yellow — **Hopeless love** |
| howtosayguide（日本語話者向け解説） | 黄色は "**unrequited love**"（片想い） |
| Petal Republic《Hanakotoba Guide》 | "yellow tulips mean **one-sided love**" |

> **结论：日语花语里黄色郁金香明确是「望みのない恋／報われぬ恋」＝没有希望的爱、得不到回报的爱（单恋）。**
> 这个读法在日语母语的花语资料里是一致的，之前标出的「开朗」来自中文花语书
> （人民日报客户端 Isunflower 那份列表），属于中文语境下的少数写法，
> **不能代表日语原义**。

**顺带一个对配色有用的差异**：日本花语与西方不同——日本红郁金香是「信頼・人気」，
黄是「片想い」；西方则是红＝爱的宣言、黄＝开朗。
所以「黑 + 黄」若配郁金香，在日语语境下读作 **「忧郁的单恋」**，比「绝望」更准，
和原型 A（恋爱 / 付出 / 自毁）的调性是吻合的。

**中文花语参考**：郁金香（黑）—— 神秘、高贵、忧郁的爱情；鸢尾 —— 绝望的爱；
龙舌兰 —— 为爱付出一切；迷迭香 —— 回忆、不想忘记过去、纪念。

### 2.2 蒲公英 —— 「无法停留的爱」+「爱的神谕」

**日语花语（用户说法已核实）**：タンポポ 的花語是
**「愛の神託」（爱的神谕）、「真実の愛」（真心的爱）、「幸せ」、「別離」**。
另有页面写作「神のお告げ、真心の愛、別離」。
「愛の神託」这个说法的来源是：蒲公英自古被用作恋占之花，
欧洲有"一口气吹光绒毛则恋情实现"的传说。

**中文花语**：无法停留的爱、至死不渝、忠贞之爱、永不停息的爱；
也有"重逢前的分离"这一支。

> 两条原型可以同时用上这两个义项：
> 中文侧「无法停留的爱」→ 成熟后自己飘走；
> 日语侧「愛の神託」→ 把爱托付给不可知的力量，这正好是"签订契约"这个动作本身。

### 2.3 蝴蝶 —— 「死与新生」

日本来源把蝴蝶明确对应为 **「変身」「変化」「再生」「復活」**：
蛹期被解释为"向一种存在方式的死"，羽化则是复活。
同时蝴蝶也是 **「自由」「解放」**（花间自由飞行）、**「死者の化身」「神や天使の使い」**，
且希腊语 ψυχή（psyche）同时指"灵魂"与"蝴蝶"，这是这层象征的源头。
日本文化中蝴蝶被视为生者与死者的灵魂；成对蝴蝶在中国象征婚姻和谐。

> 对本模组最直接的一条：**「毛虫 → 蛹 → 蝶」就是「签约 → 积累污秽 → 魔女化」的形态隐喻。**
> 原型 A 的宝石与魔女化演出可以直接沿这条线走。

来源：
- https://www.arutokoroni.jp?p=995/ （蝶々―変身/変化/再生/復活）
- https://luminamur.com/symbols/butterfly （psyche；日本：生死之魂）
- https://elderberryarts.co.uk/2025/12/30/the-spiritual-significance-of-butterflies/ （蛹=死亡/埋葬，羽化=复活）
- https://www.mikegravel.org/?p=197513 （日本：蝶=魂、 Femininity；成对=婚姻和谐）

### 2.4 蜂后与工蜂 —— 索取型与付出型的现成原型

这一节不是象征学，是**行为机制**，但对模组设计非常直接。

| | 蜂后（queen） | 工蜂（worker） |
|---|---|---|
| 谁在干活 | 不采集、不觅食、不酿蜜，**完全靠侍从喂养** | 采集、酿蜜、育幼、筑巢、守卫 |
| 寿命 | **2–5 年** | **约 6 周**（夏季工蜂"累死"） |
| 螫针 | **光滑无倒刺 → 可以反复蜇** | 倒刺 → 蜇一次就死 |
| 与基因的关系 | 与工蜂**基因完全相同**，差别只来自幼虫期**只喂蜂王浆**（表观遗传开关，抑制 Dnmt3 甲基化） | 同上，反向 |
| 怎么控制蜂群 | 靠**信息素 QMP**（上颚腺信息素）统一蜂群：抑制工蜂卵巢发育、维持分工 | 听 QMP 行事 |
| 决策权 | 养蜂界公认"蜂后不指挥，决策是工蜂做的"；她只是蜂群的载体与化学中心 | 实际决策者 |
| 死了会怎样 | 工蜂几小时内察觉 QMP 浓度骤降 → 紧急改造幼虫房为王台育新王；新王出房后**用螫针隔着房壁刺杀竞争者** | 失去 QMP 数周后部分工蜂开始产卵（只产雄蜂），种群失衡 → 蜂群崩溃 |

## 三、候选契约原型

> **2026-11-06 更新**：原型不再由玩家在菜单里选择，而是**由合成契约的材料决定**。
> 所以下面这 7 条不再是「菜单项」，而是**合成表的候选材料组合**——
> 每条对应「纸 + 学派材料 + 倾向材料」的一条 shapeless 配方。
> 倾向材料本身也要有实物载体（见 3.2）。

沿用 Part II §2.5 的三段式（授予 / 否定条件 / 副作用），每条都只用原版可检测事件。
性质词沿用原作体系（Part II 附 A）。

### 原型 A · 恋爱 / 付出 / 自毁（黑 + 黄）

| 编号 | 愿望 | 元素 | 授予 | 否定条件 | 副作用 | 性质词 |
|---|---|---|---|---|---|---|
| **A1** | 「请按照你喜欢的样子改造我吧」 | 蝴蝶（蜕变） | 指定一名同伴，宝石按对方偏好改造外观；对该同伴增益 +25% | 绑定对象死亡，或你连续 1 游戏日未与该对象交互 | 你每次变身累积"异化"，无法恢复原貌 | 执著 |
| **A2** | 「拜托你千万不要抛弃我，就这样抱着我吧」 | 黄色郁金香 | 与一名同伴共享生命：一方受伤另一方分担 30% | 绑定对象离队，或双方距离超过 32 格持续 1 游戏日 | 你无法对绑定对象造成伤害，也无法被治疗 | 渴望 |

### 3.2 倾向材料独占一套物品（已定）

既然「材料即选择」，倾向就得有对应的材料，而且**独占一套，不与学派材料混用**。

| 倾向 | 建议材料 | 理由 |
|---|---|---|
| 献身（恋爱 / 付出 / 自毁） | **黑色郁金香**（模组物品） | 黑＝忧郁之爱 + 黄＝望みのない恋 → 忧郁的单恋 |
| 索取（自私 / 逃避） | **蜂蜜瓶**（模组物品） | 蜂后＝只索取不给予；黏滞＝缠住不放 |
| 赎罪（爱 / 罪恶 / 执念 / 赎罪） | **蓝刺芹**（模组物品，暂定紫颂果 + 甘草） | 刺、刀刃、荆棘、十字架 |

- 学派材料则用**原版物品**（钻石、末影珍珠、绿宝石、烈焰粉、蓝冰、下界之星、唱片、紫颂果…），
  开箱就能拿到，不需要额外设计获取途径。
- 倾向材料是模组自己的物品，**通过箱子战利品表注入**
  （`data/forge/loot_modifiers/global_loot_modifiers.json` + `forge:add_item`）。
  这与「签约前拿不到怪物掉落物」正好构成一个闭环：
  **普通掉落物不参与合成，契约材料只从箱子里来。**

## 五、「如何成为魔法少女」：已定 —— 合成制仪式

**2026-11-06 决定**：走**仪式**，但仪式用**合成**来做。

```
契约 = 纸 + 学派材料 + 倾向材料
   ↓ 使用契约
确认界面：「你真的希望通过【自然 · 献身】成为魔法少女吗？」
   ↓ 确认
粒子动画 + 音效（3~5 秒，可跳过）
   ↓
获得灵魂宝石（不可丢弃，死亡不掉落）
```

三个原方案的去向：

| 方案 | 去向 |
|---|---|
| 甲 · 签约仪式（v1.0 三段式愿望） | **否决**。把砍掉的愿望系统捡回来，工作量不值得 |
| 乙 · 宝石即契约 | **部分保留**。宝石仍然是最终产物，只是获取方式从"直接选"变成"合成 + 仪式" |
| 丙 · 变身仪式 | **采纳并加强**。仪式不再是变身那一刻的选项，而是**合成与使用契约**两段 |

### 为什么合成比菜单好

- 选择被前移到合成台：玩家在合成的时候就已经"许愿"了，仪式感落在合成那一刻。
- 契约一旦合成出来，用不用是玩家的选择，但**材料已经交出去了**——不可逆性由"用掉契约"承担，
  而不是由菜单里的一次点击承担。
- 避开了"选学派界面"最尴尬的问题：当 9 个学派长得一模一样时，菜单没有意义；
  当它们有各自的主题与色调之后，合成台反而成了能一眼看出区别的地方。

### 这条路线还顺带解决了什么

- **不用做"选择原型"的界面**，但仍然有一次"你确定吗"——确认界面是仪式的最后一环，
  同时把学派、倾向、色调、属性、标记文案一次摊开给玩家看。
- **原型不影响数值**（已定）。两条倾向的差别只体现在外观、主题、技能方向与叙事上，
  污秽怎么涨、宝石碎不碎仍然只看设计提案 §4 的配置。数值可调性保留在配置里。

### 「签约前拿不到掉落物」带来的连锁影响

这条规则比它看起来更大，值得单独记一笔：

1. **它不是一条事件拦截规则，而是设定的自然结果。**
   我们设定里**所有怪物都是魔女眷属**，而**普通人看不见魔女眷属**（v1.0 Part II §7 的
   「平民不可见机制」，v2.0 曾列为放弃，现已恢复）。
   看不见 → 打不死 → 自然没有掉落。**不需要去清空掉落**——那样只会误伤任务物品和其他模组。
2. **签约前你是真正的普通人**——没有宝石、没有污秽、也没有魔法少女的手段。
   这段不是"变强前的过渡期"，而是**一个独立的探索阶段**：
   世界照样运转，只是怪物对你隐形。
3. **战斗收益与契约材料被彻底分开**。怪物掉落物不参与合成配方，
   契约材料自成一套并只从箱子来——这正是这条规则的目的。
4. **它让"开箱"成为一个真正的玩法动词**，而不只是找附魔。
   同时 v1.0 §7.3 的过渡体验（夜里的爆炸声、HUD 闪一帧粉色残影、
   教堂/废弃工厂里的战斗痕迹、写着某处发生过什么的"情报"物品）也跟着回来了——
   **那是普通玩家在看不见怪物的世界里唯一能感知危险的线索。**
5. **判定口径必须跟着身份走**：可见性与掉落权限按「是否曾经签约」判定，
   而不是「当前有没有契约」。否则玩家魔女化后契约结束、宝石碎裂，
   会连怪物都看不见也打不死，游戏没法继续。
6. **⚠️ 需要确认的一处后果**：同上。默认建议按"从未签约过"判定，
   做成配置项让两种口径都能切。

### 仍待定

2. **掉落白名单**的具体清单——至少要放行经验球与契约材料本身，

3. **契约材料在箱子里的概率**——学派材料与倾向材料该各占多少、开什么箱子。
4. **确认界面两套文案的最终措辞**（上面给的是草案，语气对了，字句可以再调）。
