## 零、三个原型的定位速览

| | 原型 A · 蝴蝶系 | 原型 B · 蜂后系 | 原型 C · 蓝刺芹系 |
|---|---|---|---|
| 主题 | 恋爱 / 付出 / 自毁 | 索取 / 自私 / 逃避 | 爱 / 罪恶 / 执念 / 赎罪 |
| 主色 | 黑 + 黄 | 琥珀 + 蜜 | 深蓝 + 银白 + 灰黑 |
| 主元素 | 蝴蝶、黄色郁金香 | 蜂巢、蜂蜜 | 蓝刺芹、刺、刀刃、荆棘、十字架 |
| 战斗定位 | **持续输出型**（越打越强，也越危险） | **控制 + 掠夺型**（靠敌人养自己） | **反击 + 标记型**（挨打越多越强） |
| 核心资源 | 魔力（维持花期）→ 污染 | 敌人的血/魔力 | 承受的伤害（罪责） |
| 情绪曲线 | 燃烧 | 冷静 | 压抑 |
| 魔女化概念 | 自毁的魔女 | 索取的魔女 | 错爱的魔女 |

三条线的机制互不重叠：**A 是输出曲线型**（时间维度）、**B 是资源掠夺型**（控制维度）、**C 是反击积累型**（伤害维度）。

## 一、原型 A · 蝴蝶系

> **⚠️ 本章已实现（2026-11-08）**，具体数值与代码位置见
> **`docs/献身系技能设计.md`**。本章保留原始设计推导，最终数值以那份文档为准。
>
> 实现的 5 主动：蝶翼斩 / 郁金香爆 / **花粉** / **花期** / **凋零**
> 实现的 3 被动：**献身之翼**（挂蝴蝶标记）/ **执念** / **余晖**

> 定位：持续输出型。
> 特点：**战斗越久越强，也越容易付出代价。**
> 资源循环：魔力维持花期 → 花期结束或提前崩塌 → 污染上涨。

### A-1 蝴蝶标记

攻击敌人时在其身上叠加「蝴蝶标记」。

| 项 | 设计 |
|---|---|
| 触发 | 你的**普攻**与**主动技能**命中敌人时 |
| 叠加 | 每次命中 +1 层；单个目标上限 5 层 |
| 持续 | 12 秒，每层独立计时，**全部层数一起衰减**（最后命中的那层决定总时长） |
| 视觉 | 敌人身上留下蝴蝶翅脉状的金色纹路，层数越多纹路越亮 |
| 数据 | 挂在敌人身上的 NBT / 能力：`layers`、`expireTick`、`lastHitBy`（谁打的） |

**设计意图**：标记是 A 的"燃料"，后面两个技能（花粉 / 花期）都吃它。
不做成独立技能而做成被动，是为了不占用 4 个主动技能位里的位置——**标记是被动**，A 的主动技能是花粉、花期、凋零（加上 1 个待定）。

### A-2 花粉

对**带标记的敌人**造成持续伤害。

| 项 | 设计 |
|---|---|
| 释放 | 主动技能，指定范围内所有带标记的敌人 |
| 基础伤害 | 立即伤害 X，随后 8 秒内每 0.5 秒跳一次 Y 的小额伤害 |
| 标记加成 | 每层标记 +Z% 伤害（5 层封顶） |
| 消耗 | 消耗魔力；**魔力不足时照放，但污染按 §主规则上涨** |
| 冷却 | 8 秒（象征性） |
| 反馈 | 金色花粉粒子从标记处飘出；敌人身上残留花粉纹 |

**设计意图**：A 的"收割"技能。配合标记层数，鼓励玩家先挂标记再收割。

### A-3 花期（A 的核心机制）

短时间大幅提高攻击能力，但**有代价**。

#### 状态机

```
[休眠] ──施放──> [花期·绽放] ──战斗超时(默认12秒)──> [花落] ──战斗结束──> [休眠]
                      │                                  │
                      │ 魔力耗尽                         │ 战斗中继续
                      ↓                                  ↓
                   [花落] ──战斗结束──> [休眠]      [持续花落：自身属性下降 + 污染缓慢上升]
```

#### 绽放阶段

| 项 | 设计 |
|---|---|
| 伤害加成 | 施放瞬间 +X%，随后**随战斗持续时间线性增长**，最高 +Y%（默认 12 秒到顶） |
| 魔力消耗 | 每秒消耗 M 点魔力；**魔力耗尽会立刻进入花落** |
| 加成范围 | 全部伤害（普攻与技能），走统一伤害公式 |
| 视觉 | 玩家身上开出金色纹路，随时间变亮；屏幕边缘泛暖光 |

#### 花落阶段

| 项 | 设计 |
|---|---|
| 触发 | 绽放持续时间到顶；或绽放期间魔力耗尽 |
| 立刻发生 | **失去全部伤害加成**；自身属性下降（攻击 -X%、移速 -Y%、魔力上限 -Z%） |
| 持续 | 只要还在战斗状态里，就一直处于花落 |
| 污染 | 花落期间**污染缓慢上升**（每秒 +N 点） |
| 离开战斗 | **5 秒内没有受到来自生物的伤害** → 判定离开战斗 |

#### 战斗结束判定

| 情况 | 结果 |
|---|---|
| 5 秒未受生物伤害 → 离开战斗，**未处于花落** | 无事发生。绽放的加成**直接消失**，不产生惩罚（但这段时间消耗的魔力已经没了） |
| 5 秒未受生物伤害 → 离开战斗，**已处于花落** | 额外 **+15 污染**；属性下降**保留到睡一觉起床**（可恢复，非永久） |
| 还在战斗 | 保持花落状态，持续掉属性 + 污染上升 |

> **已确认（2026-11-07）**
> - **花期持续到战斗结束为止**，不再有固定的 12 秒上限；战斗期间加成一直涨。
> - 战斗结束的判定只看**是否受到来自生物的伤害**（打出伤害不算），5 秒内没挨打即脱战。
> - 花落后的属性下降**不是永久的**：睡一觉起床就恢复。

#### 设计意图

这是 A 最像"恋爱 / 付出 / 自毁"的一层：
你越想赢，就得越久地待在战斗里；待得越久，最后那一下"花落"的代价就越重。
**而"5 秒无伤就没事"给了一个明确的止损信号**——玩家可以在花落之前主动脱离战斗，保住状态。
代价则落在"你已经拿到收益之后"的阶段。

#### 实现要点

- 需要一个**战斗状态跟踪器**：玩家数据里存 `lastCombatTick`（最后一次造成/受到伤害的时间）与 `combatTicks`（本次战斗累计时长）。
- 花期状态（阶段、开始时间、是否已花落）存在玩家数据里，需要同步到客户端做 HUD 显示。
- 魔力消耗与污染上涨都要走统一的 `SpellCasting` 流程。

### A-4 凋零

以自身生命或污染为代价，换取一次爆发伤害。

| 项 | 设计 |
|---|---|
| 释放 | 主动技能，范围爆发伤害 |
| 代价（可选二选一） | **消耗自身当前生命的 X%**，**或** **立即 +Y 点污染** |
| 伤害 | 高倍率范围伤害，倍率随"已经花落"而提高（花落后凋零更强） |
| 反制 | 如果当前生命不足以支付生命代价，则自动改为支付污染 |
| 视觉 | 玩家身体开始枯萎（黑黄纹路变灰），地面留下焦痕 |

**设计意图**：A 的"最后一搏"。它把"付出代价"变成一个**主动选择**，
和花期那种"被动滑向代价"形成对照——玩家可以主动选择用命换还是用污染换。

### A 的完整循环

```
普攻挂标记 → 放花粉收标记 → 开花期输出（魔力在烧）→
  ├─ 打得顺，12 秒后花落，属性下降 + 污染涨
  ├─ 魔力烧完提前花落
  └─ 5 秒脱战：没花落就安全退出；已花落则 +15 污染
危急时凋零：拿命或拿污染换爆发
```

## 二、原型 B · 蜂后系

> 定位：控制 + 掠夺型。
> 特点：**能控制战场，并通过敌人获取资源，而不是单纯依靠伤害。**
> 资源循环：给敌人上蜂蜜 → 从敌人身上抽（注射）→ 抽来的血/魔力变成自己的。

### B-1 蜂蜜

让敌人减速、黏滞。

| 项 | 设计 |
|---|---|
| 释放 | 主动技能，范围施加"蜂蜜"状态 |
| 减速 | 移速 -30%（可叠加，最高 -60%） |
| 黏滞 | 移动时消耗体力/停止冲刺；离开蜂蜜区域后 3 秒内仍持续减速（拖尾） |
| 持续 | 8 秒，可被"迷幻"放大 |
| 反馈 | 敌人脚下出现黏稠的蜜色地面；移动时有拉丝粒子 |

**设计意图**：B 的第一手不是打伤害，而是**让敌人待在该待的地方**，好让注射和迷幻生效。
蜂蜜还有一个隐藏价值：被蜂蜜减速的敌人更容易被"蒲公英"的种子锁定。

### B-2 注射

抽取敌人的生命或魔力。

| 项 | 设计 |
|---|---|
| 释放 | 主动技能，指定一个敌人（准星指向） |
| 抽生命 | 抽取敌人当前生命的 X% → 转为自己的生命（可超过上限的部分转为临时"溢出"，几秒内用掉或掉落） |
| 增魔力 | **命中怪物后，自身魔力值增加固定量**（眷属不需要有魔力值——它们大多不施法） |
| 冷却 | 6 秒 |
| 反馈 | 敌人身上拉出一条琥珀色细线连到玩家；玩家身边出现蜜蜂残影 |
| 副作用 | 每次注射给目标叠加 1 层"被索取"（最多 3 层，每层使其受到的伤害 +5%）——**它自己会成为更好的目标** |

**设计意图**：B 的"吃饭"技能。用敌人的资源养自己，
而"被索取"层数让敌人更脆弱，形成正反馈。

### B-3 迷幻

让敌人攻击它们的同伴。

| 项 | 设计 |
|---|---|
| 释放 | 主动技能，范围使敌人**切换攻击目标**为同伴（其他眷属） |
| 实现 | 直接改攻击目标：`mob.setTarget(otherFamiliar)` + 清空原仇恨 |
| 条件 | 目标必须是**同为眷属**的其他生物（不能打玩家），且不能对同阵营造成全额伤害（见 §阵营规则） |
| 持续 | 8 秒，之后重新索敌 |
| 反制 | 视线内没有其他眷属时无效（所以要在怪堆里用） |
| 反馈 | 敌人头顶出现旋转的幻象叠影 |

**设计意图**：B 的核心控场技。与"阵营伤害修正"直接相关——
**同阵营伤害减免 50%**，所以迷幻不会让敌人互相秒杀，但能让战场混乱、输出效率下降。

### B-4 蒲公英

释放漂浮的种子，进行追踪或范围扩散。

| 项 | 设计 |
|---|---|
| 释放 | 主动技能，生成 1 个（或数个）种子实体 |
| 追踪模式 | 种子自动飞向最近的敌人，命中后爆开成小范围黏滞/幻象 |
| 扩散模式 | 种子落地后随风扩散，覆盖一片区域，对区域内敌人施加"迷幻"（弱化版） |
| 数量 | 默认 3 个，可被"蜂群"类效果增加 |
| 视觉 | 白色绒球种子飘过战场，很好认 |

**设计意图**：对应"无法停留的爱"——种子飘走、无法停留、落点不由你决定。
它同时是 B 的"远程施加"手段，让 B 不必靠近。

### B 的完整循环

```
蜂蜜减速困住敌人 → 蒲公英种子飘过去扩散迷幻 → 敌人互相打 → 混乱中用注射抽血/抽蓝 →
  → 抽来的资源补自己的血与魔力 → 继续控场
```

## 三、原型 C · 蓝刺芹系（新增）

> 状态：**已实现**（2026-11-08）。实现级说明（数值、代码位置、已知偏差）见
> `docs/赎罪系技能设计.md`；本章保留设计意图与原始设定。

| 项 | 内容 |
|---|---|
| 主题 | 爱、罪恶、执念、赎罪 |
| 植物 | 蓝刺芹（Eryngium）—— 形似蓟，花是蓝紫色，茎带刺 |
| 配色 | 深蓝、银白、灰黑 |
| 辅助意象 | 刺、刀刃、荆棘、十字架 |
| 战斗定位 | 反击型、标记型、束缚型 |
| 情感核心 | **无法原谅自己，却不愿放弃那个人** |
| 灵感来源 | エリンジウム — 香椎モイミ |

**核心循环**：挨打 → 记下"谁打的、打了多少" → 把这份罪责攒起来 → 用它反击回去。
C 是三个里最"内向"的：她的强度来自**承受**，而不是制造。

### C-1 罪之刻印

对敌人施加罪责标记，**记录敌人对自己造成的伤害**。

| 项 | 设计 |
|---|---|
| 触发 | 被动：任何敌人对你造成伤害时，自动给它挂上罪责标记 |
| 记录 | 标记上记录：施暴者、总伤害、已结算次数 |
| 上限 | 同一敌人最多累计到总伤害的上限（比如其最大生命的 50%） |
| 用途 | 罪责值是 C 的**资源**：供"赎罪之刃"和"无法偿还的约定"消费 |
| 视觉 | 施暴者身上浮现银白色的刻印纹路，纹路随罪责值变亮 |

**注意**：罪责是**双向记忆**——C 记得谁打过她，这是"无法原谅自己"的机制化。

### C-2 荆棘之拥

生成蓝色荆棘束缚敌人，且受到持续伤害。

| 项 | 设计 |
|---|---|
| 释放 | 主动技能，范围生成荆棘地刺 |
| 束缚 | 敌人被定身（无法移动）X 秒；定身期间攻击者有几率被反刺 |
| 持续伤害 | 每秒对被束缚的敌人造成小额伤害（伤害计入罪责的反向累积） |
| 持续 | 6 秒；敌人被束缚时不能使用技能（打断施法） |
| 反刺 | 束缚期间**攻击被束缚者**的敌人会受到**自身伤害的一部分**（真实伤害，有数值上限） |
| 视觉 | 深蓝色荆棘从地面生长，缠绕敌人 |

**设计意图**：C 的束缚技，同时带反噬（打被束缚者会自己掉血）——
这是"我不原谅你，但你也别想好过"的表达。

### C-3 赎罪之刃

消耗积累的罪责，释放一次强力反击。

| 项 | 设计 |
|---|---|
| 消耗 | 消耗玩家累计的罪责值（罪责是 C 的"魔力"替代品） |
| 目标 | 自动锁定**罪责最高的敌人**（欠她最多的那个） |
| 伤害 | 高倍率单次伤害，倍率随消耗的罪责量提升 |
| 附加 | 命中时对该敌人造成"处刑"效果：无视其 50% 同阵营减免（跨阵营结算） |
| 代价 | 消耗罪责时，玩家自身也承受等量的反噬伤害（小额，但是真的） |
| 反馈 | 银白色刀刃自下而上贯穿目标 |

**设计意图**：她的输出完全来自"别人欠她的"。
反噬伤害让"用罪责攻击"这件事本身带有自伤——爱与罪恶的兑换。

### C-4 无法偿还的约定

选定一名目标，在一定时间内承受其造成的部分伤害，并将积累的伤害返还。

| 项 | 设计 |
|---|---|
| 释放 | 主动技能，指定一个敌人（不能对玩家使用） |
| 约定 | 持续 T 秒（默认 10 秒） |
| 承受 | 期间该目标对玩家造成的伤害，玩家只承受 X%（默认 30%），其余进入"约定池" |
| 返还 | 约定结束时（或目标死亡时），把约定池里的伤害**一次性返还给该目标** |
| 限制 | 每个目标同时只能存在一个约定；再次指定会替换。**不能对玩家使用**（只能对眷属） |
| 视觉 | 玩家与目标之间出现一条银白色的线；线越粗说明约定池越大 |
| 失败 | 若约定期间目标逃走/死亡未结算，则池子清空（玩家白挨了打） |

**设计意图**：C 的核心机制，也是"无法原谅自己，却不愿放弃那个人"的直译：
她**不能报复**（不原谅），但**也不放手**（不愿放弃），
所以只能把伤害记下来，在约定到期时原样奉还。

### C 的完整循环

```
被打 → 罪之刻印自动记录（罪责值涨）→
  ├─ 用荆棘之拥捆住打她的人（同时反刺自己）
  ├─ 用赎罪之刃消费罪责，爆发一次（自己吃反噬）
  └─ 用无法偿还的约定绑定一个人，挨打攒伤害，到期原样还回去
```

## 四、三个魔女化概念（结界效果）

> 与 §阵营规则配套：进入魔女的结界＝站进了她的规则里。

### A · 自毁的魔女

| 项 | 设计 |
|---|---|
| 结界效果 | 结界内的玩家**持续受到无来源的魔法伤害**（没有攻击者，看不出来源） |
| 强度 | 每秒 X 点，可无视护甲，无视同阵营减免（这是"魔女的力量"） |
| 叙事 | 她的攻击打不到人，只会烧自己；于是她烧尽周围所有人 |
| 反制 | 尽快离开结界 / 击杀魔女 |
| 表现 | 屏幕边缘持续有裂纹状紫黑纹，伴随耳鸣与心跳声 |

### B · 索取的魔女

| 项 | 设计 |
|---|---|
| 结界效果 | 结界内玩家的**属性以每分钟 1% 的速度被魔女吸取** |
| 吸取内容 | 攻击伤害、移速、魔力上限、生命上限等（"属性"泛指），逐层流失 |
| 停止条件 | 离开结界即停止；已吸取的部分在离开后**不返还**（或缓慢返还一部分？）→ 待定 |
| 叙事 | 她要的是"看着你笑"，所以她拿走你的一切，只留下那个笑 |
| 表现 | 属性条旁出现细小的琥珀色流线，指向维度外的方向 |

### C · 错爱的魔女

| 项 | 设计 |
|---|---|
| 结界效果 | 结界内玩家**造成的伤害随机传导到附近的生物身上** |
| 传导规则 | 你打了 A，结果 B 受伤；**有可能是你自己受伤** |
| 衰减 | 传导后的伤害**降低**（默认 40%） |
| 叙事 | 她的爱是认错人的，所以她的攻击总是落在别人身上 |
| 表现 | 伤害数字飘出时颜色发灰，并有一条细线指向实际受害者 |

> 这一条是三个里最"玩家自己受损"的，也是最容易造成"我不知道我在打谁"的混乱感的。
> 建议在结算时给玩家一个短暂的提示（受击者身上的连接线），否则会变成纯粹的困惑。

## 五、阵营与伤害修正（共享机制）

> **这是三个原型共用的底层规则**，也是"眷属不可见机制"的挂载点。

### 5.1 阵营划分

| 阵营 | 成员 |
|---|---|
| **魔女侧** | 魔女实体、半魔女化玩家（化身）、**所有原版敌对生物（眷属）**、魔女召唤物 |
| **魔法少女侧** | 魔法少女玩家、她们的召唤物与投射物 |

实现建议：用 Forge 的实体类型标签
`forge:entity_type` → `madoka_magic:faction_witch` / `madoka_magic:faction_magical_girl`，
玩家侧靠数据里的"是否签约"判定（动态，不能只靠标签）。

### 5.2 同阵营伤害修正

| 规则 | 效果 |
|---|---|
| **同阵营伤害减免 50%** | 魔女侧实体受到魔女侧实体造成的伤害 → ×0.5；魔法少女侧同理 |
| 跨阵营 | 不减免（正常结算） |
| 特殊 | **赎罪之刃**明确无视这 50% 减免（跨阵营结算）；**错爱魔女的结界传导伤害**额外衰减 |

### 5.3 与眷属不可见机制的关系

这两条规则共用同一套阵营判定：

- 普通人看不见**魔女侧**实体（眷属不可见机制）；
- 普通人打魔女侧实体**免伤**（同阵营减免的另一面）→ 所以普通人打不死怪物，也拿不到掉落；
- 魔法少女看得见、也打得动，但打同阵营（自家眷属）只有 50% 伤害 → **魔法少女不能把自己的眷属刷死**，这正好解释了"为什么魔法少女要靠开箱而不是刷怪拿材料"。

> 这三条合起来，构成了完整的"阵营经济"：普通玩家 → 只能开箱；
> 魔法少女 → 只能打魔女侧（跨阵营满伤），打自己的眷属效率减半。

### 5.4 需要新增的技术能力

| 能力 | 说明 |
|---|---|
| 阵营标签 | `forge:entity_type` 标签 + 玩家侧动态判定 |
| 伤害修正拦截 | `LivingHurtEvent`：查攻击方阵营 → 同阵营 ×0.5；错爱传导另外算 |
| 伤害传导 | 在伤害结算时按概率改写受害者（错爱魔女结界） |
| 战斗状态跟踪 | 每个玩家的 `lastCombatTick` / `combatTicks`（A 的花期要用） |
| 状态同步 | 花期阶段、罪责值、约定池要同步到客户端做 HUD |

## 九、已确认的规则（2026-11-07）

这一节是已经拍板的内容，其余章节按这里为准。

| # | 议题 | 结论 |
|---|---|---|
| 1 | 花期时长 | **持续到战斗结束**。战斗结束 = **5 秒内没受到来自生物的伤害**（只看挨打，不看输出）。花落后的属性下降**睡一觉起床恢复**，不是永久 |
| 2 | 花落后属性下降 | **可恢复**（睡觉 / 重生时清除） |
| 3 | C 的「无法偿还的约定」能否对玩家用 | **不能**，只能对眷属 |
| 4 | B 的「注射」抽什么 | 眷属**可以没有魔力**；改为**命中怪物后增加自身魔力** |
| 5 | 玩家单挑魔女时的阵营 | 玩家**始终是魔法少女侧**，因此**没有减免**。只有**成功击杀魔女后**，自身契约才转变为「魔女之吻」、自身化为**半魔女** |
| 6 | 技能数量 | 所有魔法少女**至少 2 主动 + 3 被动**，可多不可少 |
| 7 | 原型 C 的归类 | **单独作为一个新的魔法少女**，有自己的性质与分类。每个魔法少女 = 一个独立性质 + 一个独立分类 |

### 关于第 5 条的流程

```
魔法少女（魔法少女侧）
  ↓ 单挑魔女（此时玩家仍是魔法少女侧，无阵营减免）
  ↓ 击杀成功
契约 →「魔女之吻」，自身 → 半魔女（进入魔女侧）
  ↓
之后与魔女侧为同阵营 → 同阵营伤害减免 50%
```

这意味着"转投魔女线"是一个**不可逆的阵营迁移**，
而且转投的门槛是**独自击败一位魔女**（在对方维度里）。
